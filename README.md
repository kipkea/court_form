# ระบบออกแบบและจัดพิมพ์แบบฟอร์มอัจฉริยะ (Court Smart Form & Print Studio)
## ศาลแขวงเชียงดาว (Chiang Dao Kwaeng Court)

ระบบสร้างและจัดพิมพ์แบบฟอร์มความแม่นยำระดับมิลลิเมตรสำหรับบุคลากรศาลแขวงเชียงดาว พัฒนาด้วยสถาปัตยกรรม **Django 6.0 + ReportLab/PyMuPDF + Flutter 3.47 (Web) + PostgreSQL (`cdmc_system`)** เชื่อมต่อกับระบบรวมศูนย์ **Court Central Portal & SSO (`http://localhost:8888`)** บนพอร์ต **`8007`**

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. รองรับขนาดกระดาษหลากหลาย (Multi-Paper Size Presets & Custom)
- **A4 มาตรฐาน** (210 × 297 มม.) และ **A5 ครึ่งแผ่น** (148 × 210 มม.)
- **ซองจดหมายราชการ DL** (220 × 110 มม.), **ซอง 9×4 นิ้ว**, **ซอง C5** (229 × 162 มม.), และ **ซอง C4** (324 × 229 มม.)
- **สมุดเช็คธนาคารมาตรฐาน** (178 × 89 มม.) และ **สมุดเช็คพร้อมต้นขั้ว** (228 × 89 มม.)
- รองรับการสลับแนวตั้ง/แนวนอน และกำหนดขนาดกระดาษเอง (หน่วยมิลลิเมตร)

### 2. ขยับตำแหน่งสดบนหน้าจอ (Interactive Live Paper Canvas)
- กระดานจำลองกระดาษพร้อมไม้บรรทัดหน่วยมิลลิเมตร (มม.) และเส้นตารางช่วยจัดวาง
- คลิกลากวาง (Drag & Drop) ข้อความทุกจุดบนหน้าจอได้สดๆ พร้อมปุ่มลูกศรขยับละเอียดทีละ `0.5 มม.`
- รองรับการอัปโหลด **ภาพพื้นหลังทาบตำแหน่ง** (เช่น รูปสแกนใบเช็คหรือซองจริง) โดยเลือกได้ว่าจะพิมพ์พื้นหลังออกไปด้วย หรือพิมพ์เฉพาะตัวอักษรลงกระดาษจริง
- รองรับการตั้งค่า **ชดเชยระยะขอบเครื่องพิมพ์ (Printer Offset X/Y มม.)** แยกตามโปรไฟล์เครื่องพิมพ์

### 3. ตัวช่วยอัตโนมัติสำหรับงานเช็คและเอกสารราชการ
- แปลงจำนวนเงินตัวเลขเป็น **ตัวอักษรภาษาไทยอัตโนมัติ (BahtText)** เช่น `(-หนึ่งหมื่นห้าพันสี่ร้อยยี่สิบบาทถ้วน-)`
- แปลงวันที่เป็นรูปแบบวันที่ไทยอัตโนมัติ และช่องแยกหลัก (`box_group`) สำหรับ **รหัสไปรษณีย์ 5 ช่อง** หรือ **วันที่เช็ค 8 ช่อง**
- รองรับเส้นขีดคร่อมเช็ค `A/C PAYEE ONLY` และเส้นขีดฆ่า `หรือผู้ถือ`

### 4. ดึงข้อมูลในระบบที่กรองและอนุญาตโดย Admin + พิมพ์ชุด (Batch / Mail Merge)
- ดึงข้อมูล **บุคลากรในระบบ (`portal_users`)** และ **ข้อมูลศาล/ที่อยู่หน่วยงานมาตรฐาน (`courts`)** ที่ Admin เปิดอนุญาตและกรองไว้มาลงฟอร์มได้ในคลิกเดียว
- รองรับการนำเข้าไฟล์ **Excel (`.xlsx`) / CSV** เพื่อสั่งพิมพ์ต่อเนื่องหลายแผ่น (Batch PDF)

### 5. พิมพ์ออกเครื่องพิมพ์ / บันทึกเป็น PDF / บันทึกรูปภาพ PNG + ระบบ Audit Log
- สั่งพิมพ์ออกเครื่องพิมพ์โดยตรง, บันทึกเป็นไฟล์ **PDF** (ฟอนต์สารบรรณ `THSarabunNew`), หรือบันทึกเป็นรูปภาพ **PNG ความละเอียดสูง 300 DPI**
- บันทึก **Print Audit Log (`FormPrintLog`)** ทุกครั้งว่าใครพิมพ์อะไรไปเมื่อไหร่ จำนวนกี่แผ่น พร้อมหน้าจอตรวจสอบสำหรับ Admin
